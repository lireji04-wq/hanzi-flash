# Hanzi Flash · 闪字挑战

《闪字挑战》是一个关于视觉感知和短时记忆的互动游戏原型。游戏将汉字像素化，分三帧闪现不同的像素格，每格只出现一次。玩家需要把三次看到的信息在脑海中拼起来，猜出原来的字。你也可以输入 2 到 4 个汉字，给朋友出题。

Hanzi Flash explores visual perception and short-term memory. The game turns Chinese characters into pixels and flashes a different set of pixels in each of three frames. Players piece together what they saw and guess the characters. You can also enter two to four Chinese characters to make a challenge for a friend.
